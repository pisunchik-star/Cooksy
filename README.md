# Cooksy

Домашний сайт рецептов на HTML, CSS, JavaScript и встроенной SQLite-базе Node.js. Регистрация, вход, рецепты и загруженные фотографии хранятся на сервере; публиковать блюда могут только вошедшие пользователи.

## Запуск

Требуется Node.js 22.5 или новее. В терминале из папки `Cooksy` выполните:

```powershell
npm run dev
```

Откройте <http://localhost:3000>. `npm start` запускает тот же сервер.

Зависимости устанавливать не нужно: сервер использует встроенные модули Node.js. Команда `npm run dev` создаст базу автоматически.

## Данные

SQLite-файл находится в `data/cooksy.sqlite`. В нём хранятся пользователи, хеши паролей, сессии, рецепты, ингредиенты, шаги и фотографии. Пароли хешируются на сервере с солью; авторизация работает через HttpOnly cookie.

Для резервной копии остановите сервер и скопируйте файл базы. Не удаляйте папку `data`, если хотите сохранить опубликованные рецепты и аккаунты.

Чтобы другие люди могли пользоваться сайтом через интернет, запустите Node-сервер на доступном сервере с постоянным диском. База SQLite хранится на этом сервере и общая для его посетителей.

## Старый Next.js вариант

В проекте оставлены файлы прежнего Next.js/Supabase варианта. Для него доступны `npm run next:dev` и `npm run next:start`; для обычной версии Cooksy используйте `npm run dev`.
